UNCIV CHEAT CONSOLE — HUMAN ONLY

This update replaces the previous cheat list. Old choices have been removed.

MENU OPTIONS
- +100 / +500 Gold
- +100 / +500 Culture
- +100 / +500 Faith
- +100 / +500 Science
- Reveal the entire map
- Spawn a free Mechanized Infantry unit
- Add 1 population to the city under the selected civilian unit
- Create the Cheat Monument Wonder in the city under the selected civilian unit; when built, it grants a free Monument in every city

ACCESS
The action is available only to human-controlled civilizations. Every menu choice also has a Human player restriction. AI civilizations cannot use the menu.

INSTALL (DESKTOP)
1. Close Unciv.
2. Extract the folder "Unciv-Cheat-Console" into the Unciv mods folder.
3. Start Unciv and enable "Unciv Cheat Console" in Mods.
4. Start a new game with the mod enabled, or load a compatible save with the mod enabled.
5. Select a civilian unit standing on a city tile and click its Cheat Console action.

NOTES
- The menu opens by clicking a unit action; it is not a keyboard shortcut or a permanent toolbar button.
- Population and wonder options require the selected civilian unit to stand on a city tile, because they target "in this city".
- Mechanized Infantry and the Monument building must exist in the active ruleset.
- This is a data mod. It has not been launched in-game in this environment; verify the options with the in-game Mod checker for your exact Unciv/ruleset version.
